사용할 계정을 누르세요
선택한 이메일을 복사한 뒤 Last Z를 엽니다. 게임의 마지막 로그인 계정은 자동 변경되지 않습니다.
게임에서 할 일
  1. 프로필 → 계정
  2. 계정 전환 → 메일 계정으로 로그인
  3. 메일 주소 칸에 붙여넣기 → 로그인
  4. 인증메일이 오면 자동화가 새 6자리 인증번호를 클립보드에 복사
  5. 인증번호 칸에 붙여넣기 → 완료

✓ 메일 앱을 직접 열어 인증번호를 확인할 필요 없음

계정 이메일 설정

이메일 주소만 이 기기의 브라우저 저장소에 보관합니다. 메일 비밀번호·네이버 앱 비밀번호·인증번호는 이 웹앱에 저장하지 않습니다.





인증번호는 매번 바뀝니다. iPhone 단축어 자동화가 Apple Mail에 도착한 Last Z 메일의 콘텐츠에서 최신 6자리 번호를 추출해 클립보드에 복사합니다. Quick Switch 서버에는 메일 로그인 정보나 인증번호를 전송·저장하지 않습니다.
